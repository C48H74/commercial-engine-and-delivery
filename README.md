# commercial-engine-and-delivery

Agent skill for B2B commercial engine and project delivery: offer and pricing, sales methodologies (SPIN, MEDDPICC, JOLT, Challenger), outbound, 12-step engine with diagnosis, and project delivery (PMBOK 7, earned value, risk, status).

- Main repository (English). Translations: `motor-comercial-e-gestao-pt` (Portuguese), `motor-comercial-e-gestao-es` (Spanish).
- Start with `SKILL.md` (router). Load one module from `references/` and one template from `templates/`.
- Known limits are declared in `SKILL.md`. Figures from sales-method authors and PMI Pulse are marked as unverified where applicable.
- Validation: `node scripts/validar_skill.mjs .` and `node scripts/validar_yaml.mjs .` (Node.js; the YAML check needs the `yaml` package).
